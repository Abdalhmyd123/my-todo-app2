بناء APK يومي بدون Android Studio
1) أنشئ حسابًا على github.com ثم مستودعًا جديدًا (New repository).
2) ارفع كل محتويات هذا المجلد (Add file > Upload files). تأكد أن مجلد .github ارتفع أيضًا؛ إن لم يظهر، اختر Add file > Create new file واكتب الاسم .github/workflows/build-apk.yml والصق محتوى الملف.
3) افتح تبويب Actions > Build APK > Run workflow، وانتظر 5 إلى 10 دقائق.
4) نزّل yawmi-apk من أسفل صفحة التشغيل، وفك الضغط، ثم ثبّت app-debug.apk على هاتفك (اسمح بالتثبيت من مصدر غير معروف).
